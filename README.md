# DRE-Bench

DRE-Bench is a dynamic reasoning evaluation benchmark grounded in a hierarchical cognitive framework. DRE-Bench consists of 36 abstract reasoning tasks organized across four cognitive levels, with each task featuring multiple dynamic variants that test the same underlying latent rule. 

The structure of this code repository is organized as follows:

1、The task generator and solver code of the four cognitive levels:(1)Level-1 Attribute, (2)Level-2 Spatial, (3)Level-3 Sequential, and (4)Level-4 Conceptual, are listed in detail in DRE-Bench/code_generation_github. These generator and solver codes can dynamically generate abstract reasoning input along with its corresponding ground truths, and control the task complexity through configurable parameters.

2、The main agentic function is in DRE-Bench/Automatic agentic framework/callfun.py, which orchestrates the iterative generation of the required generators and solvers by calling different LM agents. The other folder in DRE-Bench/Automatic agentic framework shows the specific results generated by different LLM agents across various tasks.

3、The data framework of DRE-Bench is designed based on cognitive psychology, and we also conduct a human study to validate its cognitive levels. The details of the human study, including the UI interface and the task instructions, are thoroughly described in DRE-Bench/human_test, and the detailed procedure of the questionnaire can be found in DRE-Bench/human_test/README.md.
